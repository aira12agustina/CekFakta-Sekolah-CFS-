# CekFakta-Sekolah-CFS-
CekFakta Sekolah adalah platform web interaktif untuk pelajar, pengurus OSIS, dan guru guna melawan hoaks dan pesan berantai palsu di grup kelas. Platform ini dilengkapi Simulator &amp; Kalkulator Cek Fakta untuk menilai kredibilitas informasi secara otomatis serta Papan Laporan Terpusat untuk mencatat rekam jejak hoaks di sekolah secara transparan.
